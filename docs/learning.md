# 学习入口

[返回插件说明](../README.md) · [下载 JSON 示例](../examples/dialogues.json)

安装完成后，在希望学习的群里发送：

```text
/学习
```

这就是插件的学习菜单，`/学习帮助` 也可以。下面的投喂和管理操作需要 AstrBot 管理员权限。各群分别积累，不会把甲群的素材自动用于乙群。

## 上传以前的聊天记录

1. 下载上方示例，按照 `question`（对方的问题）和 `answer`（你希望学习的回复）整理历史对话。
2. 在目标群发送 `/学习上传`。
3. 在同一群内 5 分钟内发送一个 UTF-8 编码的 `.json`、`.jsonl` 或 `.txt` 文件，最多 2 MiB、2000 组问答。
4. 收到“已新增 N 条表达样例”后即已入库，下次回复可以参考，无需重启。重复导入不重复计数。

最小 JSON 文件示例：

```json
[
  {
    "question": "怎么还没发货？",
    "answer": "你是担心耽误后面的安排吧。供应商这边方便确认一下预计发货时间吗？"
  }
]
```

TXT 也可以，保存为 UTF-8：

```text
问：怎么还没发货？
答：你是担心耽误后面的安排吧。供应商这边方便确认一下预计发货时间吗？
```

每组问题最多 500 字符，回复最多 1000 字符。原始微信、QQ等聊天导出请先整理成问答格式。上传前移除不需要模型看到的个人和业务敏感内容；导入的样例会作为表达参考发送给你配置的模型。

如果聊天平台不支持文件消息，把文件放在 AstrBot 服务器的 `data/plugin_data/astrbot_plugin_human_style/inbox/`，再在目标群发送 `/学习导入 文件名.json`。该目录内的文件不会自行导入，也不需要把历史记录传到 GitHub。

## 直接教一句

```text
/学习添加 这个价格做不了。 => 明白，我们再看看数量或规格有没有调整空间，双方一起商量。
```

## 回答不好，马上纠正

机器人回复后，管理员在同一群发送：

```text
/学习纠正 你着急用吧，我们先把预计发货时间确认清楚。
```

它会把本群最近 10 分钟内最后一次完整模型回复所对应的问题，与你给出的改写组成学习样例。多人同时提问时，使用 `/学习添加 问题 => 回复` 明确指定问题更合适。

如果原回复已经很好，发送 `/学习采纳` 即可。

## 让日常对话继续积累

默认把群里不同人短时间内前后发言收集成待审候选，先查看：

```text
/学习待审
```

确认某条确实值得学习后，通过它的编号：

```text
/学习通过 12
```

候选未经确认不会影响回答。机器人自己的回复也不会自动循环灌回学习库。需要暂停收集时，发送 `/学习收集 关闭`；恢复时发送 `/学习收集 开启`。

## 看进度，调整素材

```text
/学习状态
/学习样例
/学习评分 12 +1
/学习评分 12 -1
/学习删除 12
```

正向评分提高样例参考权重，降至 -2 后停止参考。学习库会持续保存，更新插件时保留 `data/plugin_data/astrbot_plugin_human_style/` 目录即可。

这里的学习是积累和检索认可的表达，不修改 DeepSeek 参数。优先喂少量真实、自然的好对话，再根据实际回复纠正；数量增加本身不保证表达效果变好。
