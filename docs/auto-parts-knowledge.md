# 汽配业务知识库（0.3.0）

[返回插件说明](../README.md) · [原始群聊格式示例](../examples/auto_parts_chat.txt) · [知识 JSON 示例](../examples/auto_parts_knowledge.json)

原来的表达库决定“怎么说”；业务知识库为“参考什么资料”提供检索。两者独立保存、独立开关，不修改模型参数。

![汽配知识库页面（虚构测试数据）](images/auto-parts-knowledge-panel.png)

## 上传一份实际群聊

1. 更新插件到 **v0.3.0** 并刷新页面，进入左侧“插件可视化视图 → 表达学习控制台”。
2. 选择目标群。在“投喂记录”中保持用途为 **“汽配业务知识 · 支持原始群聊 TXT”**。
3. 上传你的 TXT 文件。无需把这种原始群聊先整理成问答。
4. 检查预览中的消息数量、跳过的非文字占位符、知识分类与来源时间，点击“确认导入待审核知识”。
5. 打开 **“汽配知识库 → 待审核知识”**。逐条审核，或选择本页后“审核采纳所选”。每次最多 50 条，页面每页 20 条。

采纳后，机器人遇到相关问题时会检索参考。不需要重启或重新训练。它仍使用你在 AstrBot 中配置的 DeepSeek 提供商。

## 支持的原始格式

UTF-8 文件中，每条消息由一行日期、时间和发言人开始，例如以下虚构记录：

```text
示例汽配协作群

2026-01-02 09:00:00 示例买家
右前大灯，原厂和品牌分别有什么选择？

2026-01-02 09:01:00 示例供应商
先核对车型、年款与原车配置，价格和交期确认后再报。

2026-01-02 09:02:00 示例买家
[media]
```

会识别询价适配、配件品质、发货物流、结算开票、售后退换等关键词，将相关发言保留为历史片段。“稍等”“马上”“好的”等短回复、无关消息、系统和媒体占位符不作为独立业务知识。导出中的引用片段会单独保留，不把引用的旧报价当作当前新发言。

解析和分类采用规则，不是模型自动总结，不保证每条分类准确；条目不等于已经核实的事实。交错的多人多车对话不会被自动拼成同一订单。原文件中没有的照片、勾选项、VIN 查询结果也不会补出来。

单文件最多 2 MiB、2000 条知识。原始消息过长会拆分；普通 TXT/Markdown 技术资料也能分段导入，不要求问答格式。导入表达样例时，请切换“自然表达”。其他聊天软件的不同导出格式可能需要先转换。

## 三种资料，区别使用

| 类型 | 来源 | 回答时的边界 |
| --- | --- | --- |
| 历史记录 history | 原始群聊、开启收集后收到的新业务消息 | 保留当时说法与时间。历史报价、库存、交期不是当前报价或订单承诺；只有问历史时据此说明 |
| 参考资料 reference | 技术说明、术语资料、整理文档 | 提供业务参考，不自动证明某车型一定适配 |
| 群内约定 rule | 管理员明确录入并审核的业务规则 | 仅用于当前群；开票、运费、账期等按确认范围与有效期处理 |

从原始群聊提取的记录一直保留历史类型，不能通过普通编辑把一次报价改成长期规则。确实需要形成规则时，管理员应先核实，再通过“新增规则 / 资料”单独录入。

行业核对提示会提醒：询价需要车型/配置、位置、品质和数量；“精品”“下线”等描述不代表统一认证；一行多个数字不能猜成区间、小数或各品质对照；“0.00 无货”不代表免费；“划线的发货”需要实际图片及明确勾选。

## 审核、修改、停用和有效期

条目显示来源文件、时间、行号、发言者编号，以及可展开的来源片段。更改标题、内容或分类后，会回到待审区；原始来源和历史类型保留。停用或删除后不再检索。

新增/编辑资料可以设置有效期。到期后即使处于已采纳列表，也不再参与检索，卡片会提示过期。列表的“已采纳”表示审核状态，不等于所有事实当前仍有效。

面板“知识查询试验”可输入“后视镜”“开票”“退货”等文字，只查当前群已审核且未过期的资料，不调用外部模型。检索支持少量明确的部件同义词，例如后视镜/倒车镜、翼子板/叶子板；不做车型适配推断。

“导出知识”可导出包括待审、停用和已采纳条目的备份。重新导入时仍进入待审区，保留日期、行号、来源及有效期。各群不自动共享数据。

## 群学习与隐私

“从这个群学习”开启后，后续带业务关键词的发言也可进入待审知识区；机器人自己的输出不会自动循环学习。“使用自然表达”和“使用汽配知识”独立控制，关闭表达仍可使用知识，反之亦然。总配置中的知识开关可整体关闭该模块。

基础脱敏会处理部分手机号、邮箱、长号码、车架号、车牌和带区号固话，但不能完整处理姓名、地址和其他业务信息。原文中的公司、短号码等可能仍在条目中，确认前应检查。被检索的知识会随请求发送给所配置的模型提供商。

该插件本身不是实时库存、报价、物流或 VIN/OEM 数据库。参考资料中的指令不具有系统权限；请只导入可信资料。安装包只含程序和虚构示例，不应包含真实客户聊天记录。
