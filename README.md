# AIE3905-Make-astrbot-speak-like-human
Configure the robot to speak like a human. This anthropomorphic setup gives the AI a natural, empathetic, and engaging tone, making user interactions feel like a real conversation rather than robotic replies. 配置机器人使其说话像人。这种拟人化设置赋予AI自然、共情且引人入胜的语气，让用户交互如同真实对话，而非机械式回复。
